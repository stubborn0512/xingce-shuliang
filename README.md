# 🍊 果果的行测复盘库

一个给自己用、随着备考持续更新的行测个人知识与复盘库。

> 目标：把做题时真正卡住的地方、对应课程体系下的正确思路、错题和考场识别方法，沉淀成一个随时可查的网站。

## 五大模块

- 🗣️ 言语理解
- 🧩 判断推理
- 🔢 数量关系
- 📊 资料分析
- 🧠 常识判断

## 统一复盘链路

**做题 → 疑惑/错误 → 对应体系定位 → 正确方法 → 易错点 → 同类巩固 → 掌握状态 → GitHub 长期沉淀。**

### 体系来源

- 数量关系：严格按王炎老师体系。
- 资料分析：按用户提供的《方法精讲-资料分析思维导图》整理。
- 言语理解：按用户提供的《方法精讲-言语理解思维导图》整理。
- 判断推理、常识判断：待导入对应课程体系资料。

申论为独立项目，不纳入本仓库。
