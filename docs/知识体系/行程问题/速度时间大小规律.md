> 这页先建立正式的知识档案入口。历史对话中的完整“疑惑总表”在导入前，需要以原始总结为准，不能凭记忆补写。

## 一、这页最终要记录什么

### 1. 我的原始疑问

保留我当时真正问出来的话，方便以后判断自己是不是又回到了同一个坑。

### 2. 王炎思路

严格按照课程体系记录：先定位题型，再找关键等量关系，不混用其他老师的套路。

### 3. 我的最终理解

把“为什么”压缩成考场能直接调用的一句话。

### 4. 易错点

记录容易把两个概念混在一起的地方，并给出识别关键词。

### 5. 典型母题

把不同题面归到同一个底层模型，方便举一反三。

## 二、考场复盘模板

```text
题型：

```
