## 一、做题流程

### 1. 四信息定位法

做题首先拆分四个信息：**时间、定语、主体、单位**。

### 2. 题型识别

先判断题目属于哪类关系，再进入对应公式或速算方法。不要一上来就计算。

### 3. 选项核对

完成关系式后再结合选项判断精度要求，优先使用题型对应的快速计算方式。

---

## 二、ABRX 类

思维导图中以 **A、B、R、X** 统一表示常见的基期、现期、增长率、增长量关系。

核心关系：

- `B = A × (1 + R)`
- `X = A × R`
- `R = B / A - 1`
- `X = B × R / (1 + R)`

识别关键词重点关注：**基期、现期、增长率、增长量**。

## 四、四则运算关系式

思维导图给出的识别逻辑：

- **关系式为乘法** → 求增速 → 乘积增长率
- **关系式为除法** → 求增速 → 比值增长率
- **关系式为加法** → 求增速 → 混合增长率
- **关系式为减法** → 求增速 → 差值增长率

这部分的核心不是死记名称，而是先看题目中的**关系式**。

---

## 五、固定表述识别

- 存在间隔年份 → 求增速，即间隔增长率
- 看到年均 → 求增速，即年均增长率
- 看到“拉动增长” → 拉动增长率
- 看到“贡献” → 增长贡献率

---

## 六、比值增长率与比重差识别

重点先看**选项单位/题目问法**进行单位识别：

- 选项单位为 `%` 时，重点判断是否为比值增长率；
- 选项单位为百分点评时，重点判断是否为比重差；
- 若选项单位具有实际意义的单位，则按题目所求的实际量判断。

> 这部分后续会结合具体题目继续补充，避免脱离原思维导图自行扩展规则。

---

## 七、四信息依次核对

### 时间

先锁定问的是：**现期 / 基期 / 间隔 / 年均 / 同比 / 环比**等时间口径。

### 定语与主体

必须在材料原文中找到与问题完全对应的主体和限定条件。

### 单位

重点检查：**单位、量级、倍数**。选项出现单位时尤其要回头核对。
