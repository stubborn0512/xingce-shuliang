## 🎯 这个网站干什么

这里专门沉淀备考过程中真正有价值的东西：

- **我的疑惑**：我当时到底卡在哪里？后来怎么想通？
- **错题档案**：错因、王炎方法、正确思路、再次遇到怎么识别。
- **知识体系**：按数量关系题型整理，而不是零散收藏公式。
- **考场策略**：什么题值得做、怎么快速识别、什么时候果断放弃。

## 🧭 使用方式

**做题时** → 发现新的卡点 → 记录到“我的疑惑” → 归入对应题型。

**复盘时** → 对照错误类型 → 回到对应知识点 → 做同类题巩固。

**考前** → 只看“易错”和“考场识别”，快速回忆。
