# ❓ 我的疑惑总表

这里不是“标准答案库”，而是专门记录：**我曾经为什么不懂，以及最后是怎么理解的。**

## 五大模块

- 🗣️ [言语理解疑惑](./言语理解)
- 🧩 [判断推理疑惑](./判断推理)
- 🔢 [数量关系疑惑](./数量关系)
- 📊 [资料分析疑惑](./资料分析)
- 🧠 [常识判断疑惑](./常识判断)

> 后续每产生一个有价值的疑惑，就归档到对应模块、题型和知识节点，并保留原始问题、错误原因和最终理解。

## 归档原则

1. 不把同一个问题重复写很多遍。
2. 优先记录自己真正卡过的点。
3. 每个疑惑必须落到一个明确的模块与题型/方法。
4. 对照对应老师体系复盘，不混用不同模块的方法。
5. 最终形成能在考场直接调用的识别规则。

## 记录模板

```text
模块：
章节/题型：
我的原始疑问：
我的第一反应：
错误/卡点：
对应体系：
正确理解：
易错提醒：
同类巩固：
掌握状态：
```
