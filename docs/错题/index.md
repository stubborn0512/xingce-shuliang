# ❌ 错题档案

错题不只记录答案，重点记录**为什么会错**。

## 五大模块

- 言语理解
- 判断推理
- 数量关系
- 资料分析
- 常识判断

## 每道错题固定记录

1. **题型定位**
2. **我当时的思路**
3. **错误发生在哪一步**
4. **对应老师体系的方法**
5. **正确思路**
6. **考场识别关键词**
7. **同类题巩固**
8. **掌握状态**

## 错误类型

- 题型判断
- 关键词/数据定位
- 方法/公式
- 结构分析
- 计算
- 审题
- 记忆混淆
- 其他

> 数量关系的错题继续严格按王炎体系记录；其他模块以各自提供的课程体系为准。
